# 文档导航

开发文档以中文为准；项目介绍、隐私政策和变更记录保留中英文版本。

| 需要了解 | 阅读位置 | 维护边界 |
| --- | --- | --- |

| 导航、返回、触感、圆环、图标与界面验收 | [界面与资源](ui.md) | 对照 Compose、资源和测试实现 |

每个主题只有一个维护位置；其他页面使用链接，不复制完整说明。修改功能时同步相关主题和未发布变更记录，版本号以 `app/build.gradle.kts` 为准。构建报告、截图、APK 和 R8 映射保存在已忽略的 `app/build/` / `dist/`，不把某次本机构建的路径或数量当作长期文档里的最新结果。

历史审计、图像生成提示词、探索方案和一次性验收记录的有效约定已并入上述专题；旧记录可从 Git 历史查看。文档变更后执行 `python3 scripts/check_docs.py`，检查内部链接、源码引用、版本和平台声明；构建按 [build.md](../build.md) 执行。
